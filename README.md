# 🐍 Python Learning & Assignment Repository

> Repository dùng để lưu trữ toàn bộ bài tập, project nhỏ và quá trình tự học Python từ cơ bản đến nâng cao.

---

## 👨‍🎓 Giới thiệu

Đây là repo cá nhân phục vụ mục đích:

- Học và luyện tập Python theo từng giai đoạn
- Làm bài tập trên lớp / bài tập cá nhân
- Lưu lại các project nhỏ trong quá trình học
- Rèn luyện tư duy lập trình và kỹ năng giải quyết vấn đề
- Xây dựng nền tảng để phát triển lên backend / AI / data

Repo này không phải project hoàn chỉnh mà là **hành trình học tập liên tục**.

---

## 🎯 Mục tiêu học tập

Trong quá trình sử dụng repo này, mình hướng tới:

### 🟢 Giai đoạn cơ bản
- Hiểu cú pháp Python
- Làm quen biến, kiểu dữ liệu
- Câu lệnh điều kiện (`if`, `else`)
- Vòng lặp (`for`, `while`)
- Hàm cơ bản

### 🟡 Giai đoạn trung cấp
- Lập trình hướng đối tượng (OOP)
- Xử lý file (read/write JSON, TXT)
- List comprehension
- Modules & packages
- Xử lý lỗi (try/except)

### 🔵 Giai đoạn nâng cao
- Thuật toán cơ bản (sorting, searching)
- Cấu trúc dữ liệu (stack, queue, tree cơ bản)
- API request (requests module)
- Web scraping
- Mini projects thực tế
